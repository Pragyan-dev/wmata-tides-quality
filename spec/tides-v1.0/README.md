# TIDES v1.0 schemas

Unchanged copies of files from the official TIDES repository, tag `v1.0`
(https://github.com/TIDES-transit/TIDES/tree/v1.0/spec).

The TIDES Specification is Copyright 2023 by the TIDES Board of Directors and is licensed
under CC-BY-4.0 (see LICENSE-CC-BY-4.0 in this folder).

`scripts/export_tides.py` validates the TIDES output against these copies, so validation
does not depend on the network.
